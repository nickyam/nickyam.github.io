Hexo 博客的默认分类顺序不知道是按照什么规律排序的，反正对中文分类不是很友好。如果想手动自定义分类的顺序，可以使用分类前面加上数学序号或其他特殊符号的办法。我觉得自己的网站气质稍微还是冷淡风的，不适合添加花里胡哨的符号，所以以分类前面添加数学序号为例。

因为之前已经有几十篇历史文章，如果手动一偏一篇去替换太费时间。我就用 Atom 批量替换，快捷键是 `shift + command + f`进行多文件搜索。接下来的操作和 MS Office 无异。

最终效果如下：

```
⓵随笔
⓶科技
⓷投资
⓸诗歌
⓹工作
⓺其他
```
