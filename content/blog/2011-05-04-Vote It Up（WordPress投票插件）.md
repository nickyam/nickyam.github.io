一款不错的 WordPress 日志投票插件—Vote It Up 值得大家尝试。

如果你去过 Digg，就会明白投票的意义——日志投票对于提高用户体验，增加博客的交互性很有帮助。Vote It Up 日志投票插件有后台设置，操作简单；支持 widget；支持读取投票最多的文章，有点类似评论最多的文章（most commented posts）；多种投票样式供选择等特点： 基本特点： 支持 widget； 支持读取投票最多的文章，有点类似评论最多的文章（most commented posts）； 多种投票样式供选择；

另外，也可根据自己需要自定义投票提示文字（文字或图片） 使用方法： 1. 显示投票功能： 安装好插件之后，在想要显示投票功能的地方添加如下语句即可： <? php DisplayVotes(get\_the\_ID()); ?> 2. 显示投票最多文章： <? php MostVotedAllTime(); ?>
