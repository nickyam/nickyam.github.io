最近登陆人人网的时候，发现它的页脚处在人人电台边上出现了一个新的功能，就是人人小工具。![](/images/remote/img_60b97c09_qq360.jpg "3Q")这是一个什么东西。点开来发现是一个 Widget 2.0 的页面。笔者不禁感叹，这真是一个 widget 爆发的年代啊！结合之前互联网的几大巨头的动向，笔者想谈一谈“一站式服务”之争。因为单独的 widget 早已有之，但是发展一直是不温不火。最有代表性的是 opera。关于这家传奇的浏览器公司，笔者计划之后用专题的形式来介绍给大家。这里只提一点，关于他的 widget.

从我一开始接触 opera 的时候（貌似当时还没有 chrome），我就发现了 widget,opera 的 widget 在当时看来已经很丰富了，功能的涉及面也很广，而在我眼中，他们的功能并不是很适合。可能是国外的公司在把握中国消费者的心理和习惯方面一直有欠缺。当然有人说，firefox 的插件很有名，你怎么不说？因为 firefox 的插件或者扩展的英文原文是 extension，而不是 widget（小工具，小部件）这两者是有很大区别的。前者是为了通过插件增强浏览器的功能，而后者通过小工具在浏览器中能够完成更多原本不属于浏览器范畴的功能。当然 chrome 更聪明，它的插件虽然名字和 firefox 一致，而网民也热衷于让它的插件复制火狐的插件功能，所以人们往往看到的是他们的血缘关系。自从 chrome os 的消息不胫而走的时候，你有没有发现，其实它的插件有些时候纯粹是为操作系统或者一站式服务做准备。笔者不愿意花更多地笔墨来探讨这三款非 IE 浏览器的是是非非。本文的中心是一站式服务。

所以 opera 是比较早试图提供这种一站式服务的，但是和摩托罗拉一样，它善于创新但是不善于推广，这种模式一直默默无闻。直到云计算横空出世，web os 成为闪耀的明星。笔者在之前介绍过[web os](http://rene1989.web-126.com/index.php/archives/590 "在线操作系统推荐——云专题（三）")（在线操作系统推荐）,有一个笔者看好的操作系统，是全 widget 的，定制性非常高，效果也很精致。但是现在我不能期望它有太多的作为了。因为一些网络巨头也开始着手自己的一站式服务。

那么到底什么是一站式服务？所谓的“一站式服务”其实就是只要客户有需求，一旦进入卡特的某个服务站点，所有的问题都可以解决，没有必要再找第二家。 其本质上就是系统销售服务。 原为欧美国家商业概念，即商家为赢得消费者，不断扩大经营规模和商品种类，尽最大努力满足消费者的购物所需而不需东奔西跑。简单地说，就是商家备有充足的货源让消费者在一个商店里买到几近所需的商品。当然在网络时代，虚拟世界也可以简单推广。

我们身边的一站式服务，最常见的就是网址之家，igoogle,百度个性首页，有道个性首页等等一类的网络服务；再有就是以关系网络为基础的社交网站以期为用户提供更多地服务，其中又以游戏最为突出。最近新出现的闪耀的明星是 web QQ2.0 和 360 安全桌面。

WEBQQ2.0 走的一站式网络生活服务平台，当是操作系统的路线，这是从它的类似 win 系列的界面推测的，当然它所提供的服务还仅仅限于自身的服务（辍耕录 http://rene1989.web-126.com/通过登录该网页发现，腾讯将 QQ 客户端、TT 浏览器、QQ 空间、QQ 音乐、搜搜、QQ 邮箱、微博、输入法等旗下产品进行整合，也就是说用户通过 WebQQ 2.0 可以体验到腾讯所有产品的应用服务）和一些现成公司的网络版服务。一方面说明操作的功能比较弱，另一方面发展前景很大。笔者相信腾讯的山寨能力。如果真的如消息所说，华硕的平板电脑将采用 QQ 操作系统的话，那么就让我们拭目以待。

而 360 安全桌面呢？笔者很喜欢 360 提供的服务，但也反感 360 一直打着安全的旗号。因为这个桌面客户端是为方便而设计的完全没有安全的考量。关于具体的服务，笔者也不赘述，总之还是很不错的。比较像 Mac 下的 dock。果粉会向我砸板砖，但是 360 桌面的服务就是 dock 的功能，只是没有后者精致。 至于操作系统自身提供的快捷方式，无论是 MAC 还是 WIN7 的 DOCK，都高估了国人的操作，国人对于电脑工具化的应用需求之强，探索心之弱，是大多数国外的 OS 提供商无法理解的。一谈到 360 就会想到 3721.周鸿祎这位红衣主教对数字真的很着迷。3721 当年是依附在 IE 上才红遍大江南北，而现在的 360 牢牢抓住微软操作系统，实现自己的神话。当然我不希望我所喜爱的 360 走上 3721 的老路。

在短期看来，360 桌面的形势一片大好。桌面客户端所带来的强大，基本上从每个软件都会生成一个快捷方式即可看出端倪，记得 06 还是 07 的时候，淘宝还是哪个网站做过一个实验，就是占领桌面客户端，其实就是一个 IE 打开网页的快捷方式，通过这种方式，访问量提升了 N 倍，只不过这种模式貌似违反了该网站的所谓道德初衷，仅限于实验。而腾讯最不可小觑的就是它这么多年积累起来的用户。所以它的任何一个产品上线，对于中国互联网都是一个震动。顺便插一句，这很像新浪微博和腾讯微博之争。

而人人网的小工具走的就有些不伦不类了。因为社交网站的扩展并不需要通过 widget 完成，开放 API 吸引更多的开发者入住才是明智之举。而这正是新浪微博的未来。因为你本身是一种服务，仅仅比较有包容性而已，所以社交类网络是一个软平台，widget 的出现使得定位模糊不清。当然，目前人人网仅仅在测试当中，所以我相信人人网会逐渐认清形势的。

最后我想谈的是我对一站式服务的看法。一站式服务的初衷是为人们提供便捷的通道。而在中国这片神奇的土地上，你会发现这更多地是一种圈地行为。在目前看来这一点似乎还不明朗，笔者所坚持的“信息的自由和流通”，希望网络的一站式服务不要阻碍信息的正常流通。对于提供一站式服务，我更信赖 APPSTORE 的专业性。中国的互联网在自己的领域不断做深做强才是国家、社会、人民的福音。对于信息的一站式服务，我更欣赏无觅构建的个性网络。大家认为呢？
