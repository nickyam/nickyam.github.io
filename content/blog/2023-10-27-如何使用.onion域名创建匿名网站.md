零点君很早对暗网有所了解，但也没有进一步的去搞事情。同时，我觉得还是有必要把一些资料记录下来，方便查阅。

想使用.onion 域名需要用到 Tor，也就是洋葱头。根据公开资料，洋葱头（The Onion Router）是一种软件，是第二代洋葱路由（onion routing）的一种实现，用户通过它可以在 internet 上匿名交流。

![](/images/remote/img_ec4a98f6_fcc549d33dfd18521174f.jpg)

如果你在国内，一般来说不要轻易去尝试，这行为在国内和作死的区别不是很大。

在主要操作前，准备如下：

1. 准备一台服务器，注意不能是国内的，也不能是国内服务商的。
2. 使用 CentOS，一般版本 6 以上就好。
3. 给服务器安装 nginx，并监听 8080 端口，防火墙也要开 8080 端口。

正式教程开始：

1.首先扩展 yum 源

```bash
rpm -Uvh https://dl.fedoraproject.org/pub/epel/epel-release-latest-7.noarch.rpm
rpm -Uvh https://mirror.webtatic.com/yum/el7/webtatic-release.rpm
```

2.执行指令安装 Tor

```bash
yum install -y tor
```

3.写入配置文件，Tor 源服务端口是 8080

```bash
echo “HiddenServiceDir /var/lib/tor/hidden_service/” >> /etc/tor/torrc
echo “HiddenServicePort 80 127.0.0.1:8080” >> /etc/tor/torrc
```

4.重启 Tor，然后查询自己的.onion 域名

```bash
service tor start
cat /var/lib/tor/hidden_service/hostname
```

5.在 nginx 新建一个网站，将查询出的.onion 域名绑定上去，和正常的不同，端口需要 8080。

将网站配置文件里的listen 80;改为listen 8080;

经过以上步骤，.onion 匿名网站搭建完成。当然，直接用普通浏览器是访问不了的，还需要下载一个 Tor 浏览器才能访问。

如果想进一般的暗网网站，Tor 浏览器是不够的，因为它无法阻止你被宽带运营商发现，从而查水表，需要额外带一个代理，也就是某个大家都懂的东西。
