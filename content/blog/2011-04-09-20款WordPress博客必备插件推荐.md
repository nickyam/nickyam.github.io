WordPress 插件推荐：seo 插件;数据备份管理插件;留言管理插件;投票插件;用户管理插件;投稿管理插件;手机访问插件;rss 管理插件;广告管理插件;分享插件;安全管理插件;防采集插件。

1、All in One SEO Pack

很常用的一个 SEO 插件，详细的对网站进行 SEO 管理，方便搜索引擎更快的收录

2、Google XML Sitemaps

能够生产一个 XML 格式的 sitemaps 文件，方便 Google 搜索引擎的快速收录，随着 WordPress 文章的更新而随时更新。如果你使用 Google 网站管理工具，可以把这个 sitemaps 文件提交给 Google 方便 Google 收录更快捷。

  
WordPress 留言管理插件。

3、WordPress Thread Comment

评论回复插件，可以实现评论提交 AJAX 效果盖楼留言，可以自定义设置留言盖楼高度，评论或回复评论邮件通知等功能

4、WP-RecentComments

WordPress 博客自带的最新评论功能不怎么人性化，该插件是代替默认的显示最新评论功能的插件，扩展性强。

5、WordPress 数据备份插件 WordPress Database Backup

WordPress 博客数据备份插件，使用该插件可以实现在 WordPress 博客后台对数据进行备份而无需要专门登陆

  
phpmyadmin 管理，同时可以对博客数据定时备份并通过邮箱接收备份数据

6、WordPress 用户管理插件

Members 是一个 WordPress 用户、角色和权限管理插件。通过这个插件，你可以编辑和删除指定的角色以及角色的权限，你

  
可以创建新角色，你可以设置什么样的权限可以查看哪些文章内容等等。

7、WordPress 安全插件

Login LockDown 插件，Login LockDown 插件可以进一步增强了 WordPress 的安全性。它可以限制某一个 IP 段内重复登录的失败登录次数。如果在某短时间内，同一 IP 段登录失败次数超过一定量，插件将会禁止该 IP 段的登录功能。这有效阻止了暴力

  
破解密码。

8、Breadcrumb Trail

面包屑导航插件。生成一个层级式的导航菜单，让访客更明确自己所在的页面位置。

9、WordPress 添加文章签名档插件 Add Post URL

插件的本身在于对文章进行全面管理，对每一篇文章加入属于自己的专属信息等，或者是广告，或者是文字，或者作者信息等。

10、WordPress 文章防采集插件 copyfeed

copyfeed 可以给文章加入版权声明信息，还能加入独特的数字指纹，并通过内置的功能向各大搜索引擎获

  
取记录，检查你的 feed 是否给别人非法盗用或转载。

11、WordPress 最高访问 最受欢迎 最高留言插件

WordPress popular post state 一款日志调用插件，插件数据库内自定义两个表，

可以统计点击量，也可以统计留言量。调用所有时间热门日志、一天内热门日志、 七日内热门日志、三十日内热门日志等等。

插件支持侧边栏模式，也支持根据需要代码调用。

12、WordPress 访客信息显示插件 Show Useragent

在 WordPress 评论处显示每个访客的 UA 信息，包括国籍，操作系统，浏览器，支持在后台审核评论时查看访客 UA 信息。

13、WordPress 广告插件

Post Layout 自定义广告类型，随意插入文章的任何位置，更方便的管理广告。

14、WordPress 投稿插件

uCan Post 可以产生一个功能强大的投稿功能，管理用户投稿信息。

15、WordPress 投票插件

wp-polls 是一款出色的投票管理系统插件，在 WordPress 投票插件中热度很高，它具有一个出色的功能就是能够在文章中嵌入投票选项，让文章表现的更加丰富。

16、WordPress 手机登陆面板管理插件

WordPress Mobile Pack 通过手机方法是不是不好看。它就是来解决这个问题了，插件创建人称测试了 Every single mobile。能给手机访问网站的用户带来一种不同的体验。

17、wordpress 分享插件

shareList 可以分享自己的文章到 qqzone 人人 开心 新浪 豆瓣等等……

18、WordPress 评分插件 GD Star Rating

这个插件的效果比较漂亮。通过一串星星来现实投票结果，满分十分，分越高亮的星星越多。

19、WordPress 缓存插件

WP Super Cache 插件主要功能在于提升博客的访问速度，对于数据库较大，同时在线人数较多网站很据作用。

20 WordPress rss /feed 管理插件

Ozh’ Better Feed 是一款出色的 rss 管理插件 能够自定义 html 管理，支持代码、预览模式，可以插入版权 广告等等。
