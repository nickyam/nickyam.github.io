SMSBoom 是 Github 上 一个开源有趣的 Python 短信轰炸程序，目前 Star 已有 15k，支持多线程全自动添加有效接口，异步协程百万并发，可以对指定的手机号执行短信轰炸。

原理很简单，首先是抓取很多平台注册账户发送验证码时调用的接口，然后把接口信息存储为 api.json 文件，就可以不断地向这个文件增加新的平台接口。

项目已经使用 `pyinstaller` 打包成 `EXE` 可执行文件!免去部署 `Python` 环境的烦恼,适合用于小白。

打包环境为: Windows 10 x64 Python3.8 如果 Windows 系统不是 Windows 10 64 位 版本,可能会运行失败!

- 在任意盘(除 C 盘外)中新建一个文件夹。将程序移动到其中。
- `Win+R` 打开`cmd`输入存放的盘符。例如: E: 然后 cd 到文件夹，例如 cd SMS。
- 确认 cmd 路径是 EXE 所在路径后，cmd 输入:smsboom_pyinstall.exe，若出现命令提示，则说明脚本已正常运行。
- 使用前必须更新一遍最新接口。
