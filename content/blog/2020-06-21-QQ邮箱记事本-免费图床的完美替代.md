昨天在写作的时候又因为图床的问题而犯愁，因为我觉得图片得放在自己的地盘才安心。

在偶然中，我发现 QQ 邮箱的记事本附件自带一串链接，如：

</images/remote/img_c050f242_asset.png>

我就突发奇想，这能不能直接外链到博客作为图床呢？

在昨天的 [2020债券市场一周概览（0615-0619）](/blog/bond-market-weekly-overview-0615-0619/)中，我尝试将图片用 QQ 邮箱来作为图床来源，结果加载速度很快，远超 GitHub 图床。之前的 GitHub 图床处于被屏蔽状态，国内已经完全无法访问了。

虽然暂时解决了问题，但还有几个问题需要考虑：

一是链接的稳定性如何。到今天为止，链接依然有效，有待进一步观察。

二是链接的性质到底是什么。从 <http://p.qlogo.cn/bizmail/> 部分看，似乎是 QQ 缩略图的缓存图片，这就回到问题一的稳定性。

三是链接的唯一性。我从邮箱中再次打开图片，得到的链接和前次不一样，但是两个链接都能够打开。

四是存储空间。图片的存储空间要求很高，好在 QQ 邮箱有一个 3 个月扩容的计划，我现在已经有 4096G，暂时够用。

我不知道腾讯是否会在未来某时封杀这种使用方式，但是至少图片还在邮箱里，能够归档寻找。而 QQ 邮箱在可预见的未来应该会一直存续吧。

因此，让我们放下心来，好好薅腾讯的羊毛吧。
