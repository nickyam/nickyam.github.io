一般 WordPress 用户不需要用到注册登录插件，因为并不开放注册。但对于开放注册的 WordPress 多用户博客来说，使用一些插件扩展你的注册登录功能，使其更易于用户或集成于主题中，更加美观，还是不错的。

- Theme My Login 这个插件可以把 WordPress 的注册、登录和用户个人信息页面集成到你的主题中。还支持在后台自定义登录登出路径，各个页面的标题和文字等。
- Customize Your Community 跟 Theme My Login 插件，这个 WordPress 插件也是让你基于当前主题显示注册、登录和信息页面，另外，还可以添加一个 captcha 验证到注册登录表单中。
- WP-UserLogin 添加一个登录框 Widget 到侧边栏，如果是登录状态，则显示控制面板链接。
- AJAX Login Widget++ 同样是集成注册登录表单到侧边栏，只是这个插件基于 Ajax 特效，让用户不需要重载页面即可完成注成、登录或找回密码。
- Sidebar Login 同样是集成登录框到侧边栏的 WordPress 插件。
- InsiteLogin 集成登录页面到指定的 WordPress Page 页面。
- Alkivia Community 这个 WordPress 用户插件主要包含三大功能: 自定义登录页 Logo 图标，用本地头像替换 Gravatar 头像以及自定义显示用户列表页。

- Add Logo to Admin 这个插件可以把 WordPress 登录页面的 Logo 和后台的 Logo 替换成自己的。
- Stealth Login 让你可以自定义 WordPress 的登入、登出、后台和注册的 URL 地址。
- WP User Registration 扩展 WordPress 注册信息页。比如选择密码，AIM 帐号，验证码等等。
- DRegister 扩展增强 WordPress 注册信息的页面，可把用户名这些也添加到注册页面。同时，也还扩展一些用户字段，比如性别，来自哪个城市等。这些扩展字段可选择出现在注册时的页面和用户信息界面。
- Registered Users Only 如果你拥有一个私人博客，只想给朋友或家人阅读，可以使用这个插件实现。它会向非注册的用户显示一条友好的说明信息，还可以配置访客是否可以访问你的 Feeds。
- Members Only 效果同上。功能上更高级一些。最大的不同是它通过一个唯一的 key 来判断向哪些用户展示 Feed，这比使用 Cookie 更加隐私。
