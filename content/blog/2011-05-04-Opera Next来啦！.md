下一代 opera 浏览器——Opera Next 来啦！这一版本的 opera 又会给我们带来怎样的惊喜呢？

Opera 11.00 的时候，引进了扩展的功能。现在 Opera11.50 带我们到一个新的水平！开发人员可以添加新的功能到您的快速拨号。你的鼠标点击打开一个新的选项卡可以显示实时新闻，天气预报显示，目前电子邮件通知或更多。

曾经 opera 把所有的浏览器带入了一个 Speed Dial 时代。这可以算是 opera 引领潮流的一个明证，其实 opera 一直是浏览器世界的先驱。虽然份额不温不火，但是它的这种创新精神却令人敬重和钦佩。

现在所有的浏览器都开始玩 Speed Dial，但是 opera 又开始带领大家体验 Speed Dial 和扩展插件结合的优势和乐趣。这一点即使是其他的浏览器，甚至是一直很火的 chrome 也只是那种跟风。

从右上角的图片可以看出，Opera Next 的图标颜色变了，成了银白色，但是笔者认为不如原来红色的大气。不知道在正式版的时候会不会改回去。在用户界面的左上角的菜单也有原来的红色改成了蓝色。这一点到不错。因为 opera 的发展和蓝色那种理性和冷静很搭配。

我最喜欢的功能是 gallery，也就是图册，在 Speed Dial 安装该插件之后在任何网站上的图片都可以直接选择收藏到 Speed Dial。你说是不是很酷！

其他的功能一时还没有发现，不过我觉得还是值得一试的。

最后说一声，本站点就是为了推广 opera 而把默认的浏览器设置成 opera，在 ie 下页面整体左移，在 chrome 等浏览器下也有一定的 bug.如果你支持 opera， 就请点击[www.opera.com/browser/next/](http://www.opera.com/browser/next/)。
