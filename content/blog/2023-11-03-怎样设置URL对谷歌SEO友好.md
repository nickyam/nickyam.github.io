我们建站的时候，每一篇文章都是我们的心血，总是希望让更多的小伙伴能够看到，对小伙伴有用。

如何让小伙伴能够看到我们的文章，一个很大的要素就是被搜索引擎收录。这就涉及到 SEO。而最基础的 SEO 就是为每一篇文章命名地对 SEO 友好。

下面，我们一步一步来做。

1. 从页面标题开始  
   首先用页面标题作为原始 url，在这基础上进行修改成为完美的 url。
2. 删除特殊字符  
   删除标题里的冒号、问好、逗号、句号、（）括号、 []中括号、分号等等。
3. 删除数字  
   删除标题中的数字，例如文章写了最好的 5 个旅游目的地，三个月后发现 SEO 排名很好，我们想要新增 2 个景点，标题能修改，URL 却不能改。又如我们写了 2023 年最好的 XXX，第二年标题改成了 2024 年最好的 XXX，但是 URL 也不能修改。修改了就要做 301 调整，会影响排名流量。因此最开始的 URL 里就不要加数字了。
4. 删除多余的信息  
   一是避免访客被超长的 URL 吓到，二是 URL 太长会导致超出的部分被谷歌结果截取掉而显示不出来，进而影响 URL 所要传递的信息。所以删除 URL 中不必要的信息，能使其保持简洁。
5. 把它缩短为关键字  
   经过上述步骤，可以得到一个简短的，丰富的关键词。
6. 使用小写  
   URL 使用小写字母，Wordpress 可以将 URL 自动从大写字母变成小写字母，只需要了解这一点，不必单独设置。而如果你是用 hexo 或者其他静态部署的话，可能需要自行设置。
7. 用连字符替换空格  
   URL 不能包含空格，谷歌会将空格识别成 %20。一般来说，我们把标题里的空格替换成 -。谷歌也建议不要用下划线_。
8. 采用 HTTPS  
   现在绝大多数网站都是使用 https，这是一个排名因素，保护访客隐私。
9. 非必需不使用子域名  
   一般建主站使用主域名，除非必要，不要使用子域名。因为子域名会被搜索引擎当做一个新网站。选择一个容易记住的域名，方便访客记住你，慢慢形成品牌。
10. 选择合适的顶级域名  
    一般使用 com 顶级[域名](https://limzero.com/tag/domain "域名")，尽量不要使用其他后缀。如果你是小语种，那么可以使用这个小语种国家的国别域名。除此以外，其他[域名](https://limzero.com/tag/domain "域名")在谷歌眼中和垃圾站点联系在一起。
11. 避免出现日期  
    和第三点类似，URL 链接避免出现日期，如果是新站点，在开始发布内容之前设置文章名字的 URL 永久链接设置。
12. 尽可能避免使用特殊网址参数  
    URL 参数的问号（？）通常会出现的 URL 的后面。这些参数在电子商务产品页面上很常见，可能是产品的不同尺寸和不同颜色，形成了重复页面，可以使用权威内容标签，告诉搜索引擎哪个页面最重要。

权威页面标签，放置在网页的  部分中：

```html
<link rel="canonical" href="https://example.com/sample-page/" >
```

注释：

1. link rel=canonical：带有此标记的链接是此网页的主（权威）版本。
2. href=[https://example.com/sample-page/：可以在这个网址找到权威版本。](https://example.com/sample-page/%EF%BC%9A%E5%8F%AF%E4%BB%A5%E5%9C%A8%E8%BF%99%E4%B8%AA%E7%BD%91%E5%9D%80%E6%89%BE%E5%88%B0%E6%9D%83%E5%A8%81%E7%89%88%E6%9C%AC%E3%80%82)

以上供参考。
