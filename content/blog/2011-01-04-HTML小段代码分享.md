建站必须有代码。今天我们讨论的不是整个站点框架层面的代码，而是当一个类似于 Wordpress 的[![](/images/stupid-bug-cover.jpg "stupid-bug-cover")](/images/stupid-bug-cover.jpg)程序已经构建了一个初步的站点之后进行修饰的小段代码。这些代码的效果在平时浏览网页时我们经常看到，的确也很方便。比较专业的说法是对站点进行 SEO，改善用户体验等等。但是对于普通人来说，就是让一个网站更加想一个网站。由于本站点刚刚建立不久，这些代码都经过了很好的实践验证。分享如下： 希望对大家能够有所帮助，至少是多一个代码的参考。为什么介绍 html 代码呢，而不是其他。因为 html 非常简易，只要是 html 界面，只要插入几行都能实现相应功能。

#### **1.版权信息代码：**

很多人说，网上的文章没有版权，因为随便复制粘贴就可以据为己有。版权的意义不是说一个人垄断，而是即使大规模"开源"，也能知道它是谁的成果。所以一段复制粘贴之后会附加原来网址信息的代码就出现了。这样的代码即保护了作者的版权，使用者也不用特意去加注。不是一举两得么？

```html
<script type="text/javascript">
document.body.oncopy = function () {
  setTimeout( function () {
    var text = clipboardData.getData("text");
    if (text) {
      text = text + "\r\n本篇文章来源于Bonjour! (http://blog.bluebonjour.dreamhosters.com/) 原文链接："+location.href;
      clipboardData.setData("text", text);
    }
  }, 100 )
}
</script>
```

上面这段代码就是使用在我的 bonjour 站点的版权信息代码。大家只要把 Bonjour!([http://blog.bluebonjour.dreamhosters.com/](http://blog.bluebonjour.dreamhosters.com/))这一段改成自己的，然后再 html 模式下编辑，加到网页的最后就可以了。为什么要加载在网页的最后呢？因为这样对于网页的整体加载速度影响会小一点。你可以复制一段我的文章，看看是不是粘贴之后会有我的站点的版权信息呢！如果复制粘贴之后还把原来的版权信息删去的，那就是版权的公敌了。

#### **2.分享到代码**

本来呢，我想介绍一些简易的代码给大家。现在的时代网上可以分享的地方太多，漏了那一个也不好，如果自己写代码，那么工作量不小，而且显示的效果很多时候也是差强人意的。这里介绍一个网站，叫做"分享道"，网址是[http://www.shareto.com.cn/index.html](http://www.shareto.com.cn/index.html)。大家可以去探索一下。目前他支持的分享网址已经超过五十个，各种主流的社区都能包括。还是很不错的。而且他提供了多种按钮风格供选择呢！

```html
<!-- ShareTo Button BEGIN -->
<div><a href="http://shareto.com.cn/share.html">分享到</a><span>|</span></div>
<script src="http://s.shareto.com.cn/js/shareto_button.js" type="text/javascript"></script>
<!-- ShareTo Button END -->
<!-- ShareTo Button BEGIN -->
<script src="http://s.shareto.com.cn/js/shareto_float.js#color=0&amp;align=left&amp;move=1" type="text/javascript"></script>
<!-- ShareTo Button END -->
```

上面的代码是我在分享道自定义的浮窗代码。

#### **3.音乐播放代码**

博客如果仅仅只有文字可能效果不是特别好。除非你的文字或者内容很牛。在 web 2.0 时代，在博客中插入一段背景音乐也是很不错的。我这里只介绍一种简易型的播放模式。因为我只用这一种。不是我没有其他类型的代码，而是我觉得这种最适合背景音乐。既不是全透明，让读者无法控制，也不是界面很大的喧宾夺主。

[http://www.*.com/mediadate/lxlhbcn.asf](http://www.*.com/mediadate/lxlhbcn.asf)

如果大家不认可我的想法，网上搜一下，不同的播放模式的代码有很多。

\============================================================

另外如果不作为背景播放，而是一种网页的播放器的话，我提供两个选择——

一个是雅虎的 mediaplayer，访问[http://mediaplayer.yahoo.com/](http://mediaplayer.yahoo.com/)即可。这个播放器能够播放代码所在网页的所有音频文件。播放界面也很友好哦！

比如有以下几个音频文件，

```html
<a href="http://mediaplayer.yahoo.com/example1.mp3">First link</a>
<a href="http://mediaplayer.yahoo.com/example2.mp3">Second link</a>
<a href="http://mediaplayer.yahoo.com/example3.mp3">Third link</a>
```

只要在网页末尾插入这样简单的一行代码就可以调用了。

```html
<script type="text/javascript" src="http://mediaplayer.yahoo.com/js"></script>
```

还有一个音乐服务是意赢互动 [http://www.eingzone.com/user/center.asp](http://www.eingzone.com/user/center.asp)免费注册以后就能享受代码服务。这个播放器就像其他桌面版播放器的一样友好，但是一次只能添加 20 首歌曲。这是一个缺憾。不过大家还是可以试一试的。

谷歌地图服务也可以移植了。访问[http://ditu.google.com/](http://ditu.google.com/)在地图的右上角的选项中有分享链接，呵呵呵！应该能够看到惊喜的代码了。

喜欢豆瓣的同学，也可以把豆瓣电台秀到自己的站点上来。而什么新浪微博、网易微薄之类的也都可以生成一些小小的代码供大家捣腾。

补充一句，关于豆瓣电台也可以用这段代码：

```html
<title>豆瓣电台 - happmaoo</title>
<script> window.resizeTo(420,212); </script>
<style>
  body{background:#000;}
  #douban{ position:relative; top:0px; }
</style>
<body scroll="no" topmargin="0" rightmargin="0" leftmargin="0">
```

这段代码是用在桌面上的，打开一个新建的 txt 文件，然后把这段代码敲进去，保存为 hta 文件，就可以了。双击就是简易的豆瓣电台。
